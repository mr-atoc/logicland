# 🧠 Логоленд — сайт с играми на логику

Детский сайт с логическими и математическими играми (~10 лет). Чистый JavaScript
(ES-модули), без сборки и зависимостей.

## Запуск

```bash
node server.mjs
```

Открыть http://localhost:8420. Любой другой статический сервер тоже подойдёт —
главное открывать через `http://`, а не двойным кликом по файлу (ES-модули не
работают по `file://`).

## Офлайн-режим ✈️

Сайт — PWA: при первом заходе service worker ([sw.js](sw.js)) кэширует все
файлы, и дальше сайт полностью работает без интернета (прогресс и так хранится
локально). При наличии сети кэш тихо обновляется в фоне.

**Обновление версии.** После изменения файлов нужно поднять номер `CACHE` в
`sw.js` — иначе игроки останутся на старой версии. Тогда при следующем заходе
новый service worker скачивает файлы мимо HTTP-кэша браузера (`cache: 'reload'`),
и сайт обновляется сам: на главной — перезагрузкой, на странице игры — плашкой
«Вышла новая версия», чтобы не прерывать раунд. Кнопка 🔄 в шапке делает то же
самое принудительно (чистит кэш и перерегистрирует service worker); прогресс
игроков при этом не теряется.

## Структура

```
index.html              — главная: список игр, выбор игрока
game.html               — «хост» игры: game.html?id=<id игры>
css/style.css           — общие стили
js/core/                — ядро: DOM-помощники, хранилище, профили, прогресс, PWA
js/pages/               — скрипты страниц
js/games.manifest.js    — реестр подключённых игр  ← сюда добавляются игры
js/games/<id>/game.js   — сами игры (по папке на игру)
sw.js                   — service worker (офлайн-кэш)
manifest.webmanifest    — манифест PWA
server.mjs              — статический сервер для разработки
```

## Как добавить новую игру

1. Создай папку `js/games/moya-igra/` с файлом `game.js`:

```js
export default {
  // root — DOM-элемент, куда игра рисует себя; api — связь с сайтом
  mount(root, api) {
    const state = api.loadState() ?? { /* стартовое состояние */ };
    // ... построить интерфейс внутри root ...
    // api.saveState(state)                  — сохранить состояние игры
    // api.reportResult({ score, summary })  — итог для карточки на главной
    // api.profile.name / api.profile.emoji  — текущий игрок
    // api.exit()                            — вернуться к списку игр
  },
  unmount() {},
};
```

2. Добавь файлы игры в список `ASSETS` в `sw.js` и подними номер `CACHE`
   (чтобы игра работала офлайн и обновление дошло до игроков).

3. Добавь запись в `js/games.manifest.js`:

```js
{
  id: 'moya-igra',
  title: 'Моя игра',
  description: 'Короткое описание для карточки.',
  icon: '🎲',
  tags: ['логика'],
  module: () => import('./games/moya-igra/game.js'),
},
```

Готово — игра появится на главной, прогресс будет сохраняться автоматически
для каждого игрока отдельно.

## Прогресс и профили

- Профили игроков (имя + аватар) и прогресс хранятся в localStorage браузера.
- Весь доступ к хранилищу идёт через `js/core/storage.js` — чтобы перейти на
  серверное хранение (аккаунты), достаточно заменить реализацию в этом файле
  и добавить API в `server.mjs`.
- Прогресс хранится отдельно для каждой пары «игрок + игра».
